Held-out IFC models: sources, licences and how to cite them
Downloaded 2026-10-13. Files are unmodified. If a file is ever edited, the
CC BY 4.0 licence requires stating what was changed.

Role in the thesis
  Main test models : Clinic_Architectural.ifc, Schependomlaan.ifc, AC-20-Smiley-West-10-Bldg.ifc

1. Clinic_Architectural.ifc  (Medical-Dental Clinic, architectural model)
   Tool / schema : Autodesk Revit Architecture 2011, IFC2X3
   Source        : https://github.com/buildingsmart-community/Community-Sample-Test-Files/tree/main/IFC%202.3.0.1%20(IFC%202x3)/Medical-Dental%20Clinic
   Licence       : Creative Commons Attribution 4.0 (CC BY 4.0)
   Required attribution (from the dataset README):
     BSI (2020) "Medical-Dental Test Files," buildingSMART International, plus the GitHub URL above.
   Suggested reference:
     buildingSMART International (2020). Medical-Dental Clinic test files [IFC dataset].
     buildingSMART Community Sample Test Files. Licensed under CC BY 4.0.
     https://github.com/buildingsmart-community/Community-Sample-Test-Files
   Note: real two-storey clinic, redacted; originally provided to the US Construction
   Engineering Research Laboratory and hosted by NIBS from 2010 to 2020.


2. Schependomlaan.ifc  (design model, original file name "IFC Schependomlaan.ifc")
   Tool / schema : ArchiCAD, IFC2X3, millimetre units
   Source        : https://github.com/buildingsmart-community/Community-Sample-Test-Files/tree/main/IFC%202.3.0.1%20(IFC%202x3)/Schependomlaan/Design%20model%20IFC
   Licence       : The README states that all data owners have given permission to use the
                   data for scientific and academic purposes.
   Attribution (from the dataset README):
     Design model made in ArchiCAD by ROOT bv for Hendriks Bouw en Ontwikkeling. Data
     gathered during the master thesis project of Stijn van Schaijk at the Information
     Systems for the Built Environment (ISBE) group, TU Eindhoven, in collaboration with
     Hendriks Bouw en Ontwikkeling, ROOT, TNO and RAAMAC.
   Suggested reference:
     van Schaijk, S. (dataset author). Dataset Schependomlaan [IFC dataset]. TU Eindhoven,
     ISBE group; design model by ROOT bv. buildingSMART Community Sample Test Files.
     https://github.com/buildingsmart-community/Community-Sample-Test-Files
   TODO: check whether a thesis or paper by van Schaijk should be cited instead.
   Note: real residential project in Nijmegen. The README warns that some files contain
   errors. The same folder holds a Solibri model-quality check of this model as BCF
   (ROOT-Compleet interne modelkwaliteit.bcfzip), which was not downloaded.


3. AC-20-Smiley-West-10-Bldg.ifc  (KIT "Smiley West", terraced houses)
   Tool / schema : ArchiCAD 20, IFC4
   Source        : https://www.ifcwiki.org/index.php?title=KIT_IFC_Examples
                   (downloaded as AC-20-Smiley-West-10-Bldg.zip)
   Licence       : "for unrestricted use" (KIT IFC Examples page)
   Required attribution (from the KIT page, for publications):
     Institute for Automation and Applied Informatics (IAI) / Karlsruhe Institute of
     Technology (KIT)
   Suggested reference:
     Institute for Automation and Applied Informatics (IAI), Karlsruhe Institute of
     Technology (KIT). Smiley West (IFC4 example model, ArchiCAD 20) [IFC dataset].
     https://www.ifcwiki.org/index.php?title=KIT_IFC_Examples

5. Duplex_A_20110907.ifc  (Duplex Apartment, architectural model, pilot only)
   Tool / schema : Autodesk Revit Architecture 2011, IFC2X3
   Source        : https://github.com/buildingsmart-community/Community-Sample-Test-Files/tree/main/IFC%202.3.0.1%20(IFC%202x3)/Duplex%20Apartment

   Required attribution (from the dataset README):
     BSI (2020) "Duplex Apartment Test Files," buildingSMART International, plus the GitHub URL above.
   Cite only if the pilot is mentioned in the thesis.
